How to read this. The topic orders is not a box of its own: it is 3 partitions, and every partition is stored on all 3 brokers. Inside each broker you see the copies it holds. The bright row is the leader copy, the one producers write to and consumers read from; dim rows are followers kept in sync. Consumer groups on the right read from the leaders, each partition owned by one member per group. Use the steppers to add members: with 3 partitions, a 4th member gets nothing. The small cells on a partition are its latest offsets, colored by what happened to them. Each worker takes about 3 s per order so you can watch it. Send one order, follow the dots. (Workers also report results on a second topic, order-status, which this page reads. Not drawn here.)
